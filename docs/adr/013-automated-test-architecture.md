
# Automated Test Architecture for Game State Analyzer

This document describes the current automated testing architecture for the Game State Analyzer, as implemented in the codebase (2026).

## Overview

Automated tests for the analyzer are implemented as a comprehensive pytest suite in `tests/test_automated_levels.py` and related files. These tests:
- Cover static screenshots, negative/positive cases, and live capture
- Use subprocess calls to `analyzer_cli.py` for CLI-based analysis
- Validate output files, detection messages, and regression behavior
- Are integrated with CI and the Makefile (see `make test` and `make test-perf`)

## Test Types

### 1. Static Screenshot Regression Tests
- Run on known reference images (e.g., `RESPAWN.png`, `RESPAWNB.png`, `RESPAWNC.png`, `RESPAWND.png`)
- Validate correct detection (positive) and rejection (negative) of respawn state
- Generate and check grid overlay images (`output_grid.png`, `output_grid_highlighted.png`)
- Example (from test_automated_levels.py):
	```python
	def test_level1_static_screenshot():
			...
			cmd = f"uv run python analyzer_cli.py {path} --grid"
			...
	```

### 2. Live Capture Test
- Captures a screenshot from the configured monitor/region
- Runs analyzer and grid-based analysis on the captured image
- Validates end-to-end pipeline in the current environment
- Example (from test_automated_levels.py):
	```python
	def test_level2_live_capture():
			...
			cmd = f"uv run python analyzer_cli.py --capture"
			...
	```

### 3. Robustness and Regression
- Additional tests cover OCR robustness (e.g., discolored images, Levenshtein distance)
- Batch testing and output validation for multiple images

## How to Run Automated Tests

- **All tests:**
	```sh
	make test
	# or
	uv run pytest tests/test_automated_levels.py --html=tests/test-output/report.html --self-contained-html
	```
- **Performance/CI workflow:**
	```sh
	make test-perf
	```
- **Individual tests:**
	```sh
	make test1   # Region 33 OCR test
	make test2   # Region 9 OCR test
	```

## Output Files

- `output_grid.png`, `output_grid_highlighted.png`: Grid overlays for region-based detection
- `tests/test-output/report.html`: HTML test report
- Additional files as generated by analyzer_cli.py and test scripts

## Notes
- The old two-level CLI workflow (as previously documented) is now superseded by automated pytest-based regression tests.
- All test logic, validation, and output checking is automated; manual inspection is optional.
- See `tests/test_automated_levels.py` and `tests/analyzer_cli.py` for implementation details.
- Ensure your `config.yaml` is set up correctly for your monitor and region before running live capture tests.
